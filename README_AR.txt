BO3 Control Center - حزمة المشروع v0.3.1

الهدف
إنتاج ملف BO3-Control-Center.exe مستقل يعمل على Windows 10 دون تثبيت Python على جهاز الاستخدام النهائي.

ما الجديد في v0.3.1
- الحفاظ على الواجهة البنفسجية والسوداء (#493072) ونموذج Tkinter الحالي.
- الإبقاء على صفحات Multiplayer وZombies لتسجيل قوائم الجاهزية وملاحظات الجلسات محليًا.
- حصر اختبار Ping في عناوين IPv4 المحلية: الشبكات الخاصة 10/8 و172.16/12 و192.168/16، وعناوين Link-local وLoopback.
- نقل نتائج Ping من خيط العمل إلى واجهة Tkinter عبر Queue؛ تحديث عناصر الواجهة يتم على الخيط الرئيسي فقط.
- تنظيف ملاحظات المستخدم قبل تسجيلها، ومنع إدخال أسطر متعددة أو محارف تحكم داخل سجل الحدث الواحد.
- تحسين رسائل حالة حفظ الإعدادات وملف السجل، ومعالجة فشل فتح مجلد بيانات التطبيق.
- الحفاظ على تدوير سجل الأحداث المحلي عند 512 KB مع نسختين احتياطيتين.
- إضافة اختبارات لعناوين الشبكة المحلية وتنظيف نصوص السجل وأوامر Ping.

الخصوصية والسلامة
هذا البرنامج للمراقبة المحلية وتدوين الملاحظات فقط. لا يتصل بخوادم اللعبة، ولا يقرأ ذاكرة اللعبة، ولا يعدّل ملفات اللعبة أو بيانات الحساب، ولا يتجاوز حماية المنصة. لا تدخل كلمات مرور أو رموز تحقق. اختبار Ping لا يثبت الاتصال بخدمات BO3.

تحديث مستودع GitHub الحالي
المستودع الحالي المرئي على GitHub ما زال يحتوي على ملفات الإصدار السابق فقط. استخدم هذه الحزمة لتحديث المستودع:
- استبدل BO3_Control_Center.py وREADME_AR.txt وbuild_windows.bat بالنسخ الموجودة هنا.
- أضف tests/test_network_helpers.py داخل مجلد tests.
- أضف ملف سير العمل من المسار .github/workflows/build-windows.yml.
- ملف GITHUB_WORKFLOW_SETUP_AR.txt مرجع لنسخ محتوى Workflow يدويًا من الآيفون، ولا يلزم رفعه إلى المستودع.

البناء على GitHub
1) بعد رفع الملفات، افتح تبويب Actions في المستودع.
2) اختر Build Windows EXE ثم Run workflow، أو انتظر تشغيله تلقائيًا بعد التحديث على main.
3) لا تعتبر البناء ناجحًا إلا إذا اكتملت خطوات Syntax وUnit tests وPyInstaller وVerify EXE output بنجاح.
4) افتح صفحة التشغيل المكتمل ونزّل Artifact باسم BO3-Control-Center-Windows10.
5) فك ضغط Artifact على كمبيوتر Windows 10 وشغّل BO3-Control-Center.exe.

البناء محليًا على Windows
1) يلزم Python مع Tkinter على جهاز البناء فقط.
2) شغّل build_windows.bat.
3) بعد نجاح الصياغة والاختبارات والبناء ستجد الملف في dist\BO3-Control-Center.exe.

التحقق اليدوي
شغّل:
python -m py_compile BO3_Control_Center.py
python -m unittest discover -s tests -v

حدود الاختبار في هذه الحزمة
يمكن التحقق من الصياغة والاختبارات المساعدة وفتح الواجهة في بيئة Linux/Xvfb. لا يُعد ذلك اختبار تشغيل على Windows. يجب انتظار نجاح GitHub Actions على Windows قبل اعتبار ملف EXE جاهزًا.
